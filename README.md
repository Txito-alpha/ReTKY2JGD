# ReTKY2JGD

日本測地系（**Tokyo Datum**）から世界測地系（**JGD2000**）へ**簡易変換**された国有林GISデータを、いったん逆変換してTokyo Datumへ戻し、**正式なTKY2JGD変換**（`TKY2JGD.gsb`によるグリッド補正）を適用して、より正確な座標へ補正するQGISプラグインです。

[English README](README.en.md)

![QGIS](https://img.shields.io/badge/QGIS-3.34%E2%80%933.99-green)
![Version](https://img.shields.io/badge/version-1.3.0-blue)

## 背景

林野庁がG空間情報センターで公開する[国有林GISデータ（2025.3公開）](https://www.geospatial.jp/ckan/dataset/a45)は、一部が**簡易変換**（座標系原点の3パラメータ近似によるHelmert変換）によりJGD2000へ変換されています。この方法では地域によって数十cm〜数mの誤差が残ります。

正式な座標系変換（`TKY2JGD.gsb`によるグリッド補正）を行うには、いったん元のTokyo Datumへ座標を戻し、そこから改めてTKY2JGDを適用する必要があります。公式データは今後修正される可能性がありますが、本データを用いて作成した成果物が紙ベース等で既に残されている場合には、同様の補正作業が必要になります。

本プラグインは、この2段階の再変換処理をQGIS上で実行できるようにしたものです。以前はQGISモデルデザイナー用の `.model3` ファイルとExcelマクロによるバッチリスト生成で同様の作業を行っていましたが、現在はQGISプラグインとして単一の操作にまとめています。

## ⚠️ 使用前に必ずお読みください

### 1. TKY2JGD.gsb は同梱していません

本プラグインは国土地理院の座標変換パラメータファイル `TKY2JGD.gsb` を利用しますが、**再配布はしていません**。以下のいずれかから正規に入手し、配置してください。

- 国土地理院（[座標変換パラメータのページ](https://www.gsi.go.jp/sokuchikijun/sokuchikijun41012.html#zahyo)）
- tohka氏公開の [JapanGridShift](https://github.com/tohka/JapanGridShift)（入手元として利用する場合は同リポジトリの注意事項も併せてご確認ください）

入手したファイルは以下のいずれかへ配置します。

- `ReTKY2JGD/data/TKY2JGD.gsb`（プラグインフォルダ内。推奨）
- QGISのPROJデータフォルダ（`QgsApplication.projPath()` が返す場所）

大文字小文字は `TKY2JGD.gsb` / `tky2jgd.gsb` のどちらでも検出します。見つからない場合は配置先パスを示すエラーが表示されます。

### 2. 対象データが限定されます

本プラグインは、**簡易変換によってTokyo DatumからJGD2000へ変換済みのデータ**専用です。

- 最初から正しくTKY2JGDで変換されたデータに適用すると、**座標が二重にずれて壊れます**。
- 元からJGD2000等の世界測地系で測量されたデータに適用してもいけません。

### 3. 入力レイヤのCRS情報は使用しません

入力レイヤに設定されているCRSは**参照しません**。ダイアログで選択した平面直角座標系（EPSG:2443〜2461）を強制的に割り当てて処理します。**系番号を誤ると結果は正しくなりません。**

### 4. 地震に伴う地殻変動パラメータは対象外です

本プラグインが行うのは、**簡易変換の誤差を解消してTKY2JGDによる測地系変換を正しく適用し直す処理のみ**です。東北地方太平洋沖地震（`touhokutaiheiyouoki2011`）等、地震に伴う地殻変動の補正パラメータは別途適用する必要があります。本プラグインの変換結果を**測量成果としてそのまま使用することは想定していません**。使用にあたっては必ず現地測量や公式成果と照合してください。

## 変換の仕組み

3パラメータのHelmert簡易変換（`x=146.414, y=-507.337, z=-680.507`）で生じた誤差を解消するため、次の3工程を明示的なPROJパイプラインで実行します。

| 工程 | 処理内容 |
|------|---------|
| 1 | 選択した平面直角座標系（EPSG:2443〜2461）をレイヤへ割り当て |
| 2 | 横メルカトル図法の逆算 → 簡易変換（Helmert）を逆向きに適用し、Tokyo Datum地理座標（EPSG:4301）へ戻す |
| 3 | `TKY2JGD.gsb` によるグリッドシフト → 同じ系の平面直角座標へ再投影 |

投影パラメータは各系の原点緯度・原点経度、縮尺係数 `k=0.9999`、準拠楕円体GRS80（工程2の逆算側はBessel）を使用します。QGIS Processingの `native:assignprojection` と `native:reprojectlayer` を、`OPERATION` にパイプライン文字列を明示指定して呼び出しているため、実行環境のCRS設定に依存せず結果が再現します。

## インストール

1. [Releases](../../releases) からZIPをダウンロードします。
2. QGISの **プラグイン → プラグインの管理とインストール → ZIPからインストール** で導入します。
3. 正規に入手した `TKY2JGD.gsb` を `ReTKY2JGD/data/` に配置します。
4. メニュー **プラグイン → 国有林ツール → TKY2JGDで再変換**、または **国有林ツールバー** のアイコンから起動します。

> 「国有林ツールバー」（内部識別名 `NationalForestToolbar`）は他の国有林向けプラグインと共用します。既存のツールバーがあれば再利用し、なければ新規作成します。

## 使い方

### 座標系の選択

平面直角座標系I系〜XIX系（EPSG:2443〜2461）から対象の系を選択します。プルダウンには系番号・EPSGコード・原点座標・該当都道府県が表示されます。入力レイヤに平面直角座標系のCRSが設定されている場合は、その系が初期選択されます（**確認は必須です**）。

系の一覧は `data/zone_parameters.csv` から読み込みます。19系すべてが揃っていない場合はエラーになります。

### モードA: 単一レイヤを変換

1. **入力ベクタレイヤ**: プロジェクト内のベクタレイヤから選択します（起動時のアクティブレイヤが初期値）。
2. **出力ファイル**: GeoPackage（`.gpkg`）またはShapefile（`.shp`）を指定します。それ以外の拡張子は受け付けません。
3. **実行**をクリックすると変換が行われ、出力レイヤが自動的にプロジェクトへ追加されます。

元ファイルは上書きしません。

### モードB: ディレクトリ以下のShapefileを一括変換

1. **入力ディレクトリ**: 直下および全サブフォルダの `.shp` を再帰的に処理します。
2. **出力ディレクトリ**: 入力ディレクトリを参照すると `<入力名>_converted` が自動入力されます。存在しない場合は実行時に作成します。
3. **ファイル名末尾**: 出力ファイル名に付ける接尾辞。既定値は `_convert`、空欄にすると元と同じファイル名になります。

**入力側のフォルダ構成をそのまま出力側へ再現します**（Shapefileを含まない空フォルダも作成）。

```text
入力                          出力（末尾 _convert）
貸与データ/                   貸与データ_converted/
├─ A.shp                      ├─ A_convert.shp
├─ 地区1/                     ├─ 地区1/
│  └─ B.shp                   │  └─ B_convert.shp
└─ 地区2/                     └─ 地区2/
   └─ 年度別/                    └─ 年度別/
      └─ C.shp                      └─ C_convert.shp
```

一括変換の制約:

- **出力ディレクトリを入力ディレクトリの内部に指定することはできません**（変換結果の再取り込みを防ぐため）。
- シンボリックリンク先のディレクトリは追跡しません。
- 一括変換の結果はQGISプロジェクトへ自動追加しません。完了後に出力先を確認してください。
- 処理対象はShapefileのみです（GeoPackage等は単一レイヤモードをご利用ください）。

### 進行状況とキャンセル

一括変換では、対象ファイル数×3工程を基準とした進行状況と、処理中の相対パス・工程名を表示します。

「キャンセル」を押すとQGIS Processingへキャンセル要求を送り、実行中のアルゴリズムが要求を受け付けた時点で停止します。データ量によっては反映まで時間がかかります。既に正常終了した出力はそのまま残し、処理途中だったShapefileの不完全な構成ファイル（`.shp` `.shx` `.dbf` `.prj` `.cpg` `.qpj`）は削除を試みます。

## 文字コードの扱い

過去の日本測地系データはDBFがShift_JISで記録されている場合がほとんどのため、以下のように固定しています。

| 対象 | エンコーディング |
|------|----------------|
| Shapefile入力 | `Shift_JIS`（プロバイダエンコーディングを明示指定し、文字化けを防止） |
| Shapefile出力 | DBFを `Shift_JIS` で保存し、同名の `.cpg` に `Shift_JIS` を明記 |
| GeoPackage出力 | `UTF-8`（仕様準拠） |

## 検証のお願い

座標変換は結果の検証が不可欠です。以下を必ず実施してください。

- 既知点（三角点・基準点等）または同一地物で、変換前後の座標差を測定する。
- 変換量が想定範囲（簡易変換の残差、概ね数十cm〜数m）に収まっているか確認する。
- **系境界付近、離島、`TKY2JGD.gsb` のグリッド範囲外**のデータは個別に確認する。グリッド範囲外では期待した補正が行われません。
- 地震に伴う地殻変動が生じている地域では、TKY2JGD補正のみでは測量成果として不十分な場合があります。必要に応じて別途の補正パラメータを適用してください。

`data/reference/` に、対応表の根拠とした平面直角座標系原点のExcelと、XII系（EPSG:2454）のProcessingモデル（`.model3`）を同梱しています。処理内容の検証にご利用ください。

`TKY2JGD.gsb` は同梱されていません。リポジトリにもコミットしないでください（`.gitignore` に追加することを推奨します）。

## 既知の制限事項

- 入力データが本当に簡易変換済みかどうかを**自動判定する仕組みはありません**。利用者の判断に委ねられます。
- 選択した系が正しいかの検証も行いません。
- 一括変換はShapefileのみが対象です。
- 変換対象は水平座標のみです。標高値（Z値）の変換は行いません。
- 地震に伴う地殻変動の補正パラメータは対象外です。
- UIは日本語のみです。
