# ReTKY2JGD

Version 1.3.0

QGIS 3.34向けプラグインです。簡易変換済みの平面直角座標データをいったんTokyo地理座標へ逆変換し、`TKY2JGD.gsb` を使ってJGD2000平面直角座標へ再変換します。

## インストール

1. `ReTKY2JGD.zip` をQGISの「ZIPからインストール」で導入します。
2. 正規に入手した `TKY2JGD.gsb` をプラグイン内の `data/TKY2JGD.gsb` に配置します。
3. 「国有林ツール」メニューまたは「国有林ツールバー」から起動します。

## 重要な前提

- 対象は、簡易変換により日本測地系から世界測地系へ変換済みのベクタデータです。
- 入力レイヤに付いているCRS情報は採用せず、画面で選択したEPSG:2443から2461を割り当てて処理します。
- 系番号を誤ると結果は正しくなりません。
- 元ファイルは上書きせず、GeoPackageまたはShapefileへ出力します。

## 対応表

実行時は `data/zone_parameters.csv` を読み込みます。これは添付Excelの19系対応表を、QGIS付属Pythonだけで安定して読めるCSVへ転記したものです。根拠資料として元ExcelとEPSG:2454モデルを `data/reference` に同梱しています。

## 検証推奨

既知点または同一地物で、元の簡易変換結果と再変換結果の差を測定してください。特に系境界、離島、グリッド範囲外のデータは個別確認が必要です。


## 文字コード

- 入力がShapefileの場合、属性文字コードを `Shift_JIS` として読み込みます。
- Shapefile出力ではDBFを `Shift_JIS` で保存し、同名の `.cpg` に `Shift_JIS` を明記します。
- GeoPackage出力は仕様に合わせてUTF-8です。


## ディレクトリ一括変換

- 入力ディレクトリ以下の全Shapefileを再帰的に処理します。
- 出力は必ず入力ディレクトリの外側にある別ディレクトリへ保存します。未作成の出力ディレクトリは実行時に作成します。
- 入力側のサブフォルダ構成を出力側へそのまま再現します。Shapefileが存在しない空フォルダも作成します。
- 出力名は元ファイルのベース名を引き継ぎ、任意の末尾文字列を追加できます。既定値は `_convert` です。
- 末尾を空欄にすると元と同じファイル名になります。
- 一括出力もDBFと `.cpg` はShift_JISです。
- 一括処理したレイヤはQGISプロジェクトへ自動追加しません。完了後に出力ディレクトリを確認してください。


### 再帰処理の例

入力:

```text
貸与データ/
├─ A.shp
├─ 地区1/
│  └─ B.shp
└─ 地区2/
   └─ 年度別/
      └─ C.shp
```

末尾を `_convert` とした出力:

```text
貸与データ_converted/
├─ A_convert.shp
├─ 地区1/
│  └─ B_convert.shp
└─ 地区2/
   └─ 年度別/
      └─ C_convert.shp
```

シンボリックリンク先のディレクトリは追跡しません。また、再取り込みを防止するため、出力ディレクトリを入力ディレクトリ内部に指定することはできません。


## 進行状況とキャンセル

- ディレクトリ一括変換では、対象Shapefile数と各ファイル内の3工程を基準に進行状況を表示します。
- 進行画面には現在処理中の相対パスと工程を表示します。
- 「キャンセル」を押すとQGIS Processingへキャンセル要求を送り、現在のアルゴリズムが要求を受け付けた時点で停止します。
- 既に正常終了した出力は残します。処理中だったShapefileの不完全な構成ファイルは削除を試みます。
- Processingアルゴリズムの内部処理中は、データ量によってキャンセル反映まで時間がかかる場合があります。
